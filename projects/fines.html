처리 순서

원천 파일에서 보고서까지

계약·투자자 원천자료를 보고 항목별로 집계하는 도구입니다. 입력 파일 검사와 보고서 계산을 나누고, 원천 행 수와 잔액 합계를 검증표에 남깁니다.

  1. 01

    Excel 입력

    DB에서 내보낸 계약·투자자 원천자료를 넣습니다.

  2. 02

    열·기준월 검사

    필수 열과 같은 월의 파일 중복을 확인합니다.

  3. 03

    Sheets 업로드

    선택한 열을 보고서별 원천 탭에 올립니다.

  4. 04

    재계산 실행

    사용자가 Google Sheets에서 보고서 재계산을 실행합니다.

  5. 05

    보고서 산출

    Apps Script가 집계하고 보고서·검증표·실행로그를 갱신합니다.

01 / 원천자료 입력

파일별 열과 기준월 검사

계약·투자자 자료의 헤더와 파일 유형을 읽고 필요한 열을 선택합니다. 기준월과 필수 열을 검사한 뒤 원천 탭에 올립니다.

02 / 집계·보고서 생성

보고서와 검증표 작성

시트에서 재계산을 실행하면 계약번호로 자료를 연결하고 투자자·상품 분류를 정리합니다. 보고서 항목별로 집계한 뒤 원천 행 수와 잔액 합계를 검증표에 기록합니다.

공개 화면의 등록번호는 삭제했습니다. 회사명과 개인·문서 식별정보는 예시로 치환했습니다.

원천자료·중간 계산·보고서 탭을 나눠 계산에 사용한 자료를 확인할 수 있습니다. 실행로그에는 계산 시작·종료 시각, 기준월과 자료 건수를 남깁니다.

03 / 외부 API 연동

Google 문서 연결과 계산 코드 설치

서비스 계정으로 Sheets에 접근합니다. Google OAuth 인증 후 Apps Script API로 업무보고서·상시감시보고서 문서에 각각 계산 코드를 설치합니다.

04 / 구현 구성

파일 처리와 온라인 보고서 계산

런처에서 로컬 서버를 시작하면 입력 화면이 열립니다. 파일 처리는 Python, 온라인 보고서 계산은 Apps Script가 맡습니다.

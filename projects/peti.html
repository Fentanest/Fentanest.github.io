PETI / FILE CONVERSION

PETI
공직윤리 TXT를 엑셀로

공직윤리시스템에서 내려받은 여러 TXT 파일을
전산 입력용 엑셀 한 파일로 합칩니다.

실무 성과

수십~수백 개 TXT, 한 번에 처리

기관별 요청량에 따라 늘어나는 파일을 일괄 병합·파싱해, 실무자가 복사·분리·저장에 쓰던 반복 업무 시간을 크게 줄였습니다.

Go · JavaScriptWails · Excelize여러 파일을 한 번에
저장소·실행파일 ↗문서·파일 자동화 ↗
개발·업무 적용실행 화면주요 기능사용한 기술
개발 배경 · 업무 적용

전산에 넣기 전, 파일마다 반복하던 작업

TXT로 받고, XLS로 입력하는 업무

공직윤리시스템에서 받은 재산 조회 요청은 |로 구분된 TXT 파일이었지만, 사내 전산에 입력하려면 엑셀 파일이 필요했습니다. 파일 내용을 복사해 엑셀에 붙여 넣고, 텍스트 나누기를 실행한 뒤 XLS로 저장하는 작업을 반복했습니다.

요청 파일을 모아 한 번에 변환

기관별 요청량에 따라 수십~수백 개가 되는 파일을 한 번에 선택해 병합·파싱하도록 만들었습니다. 정해진 7개 항목을 나누고 식별번호를 보존한 엑셀을 만들어, 실무자가 파일을 하나씩 정리하는 단계를 줄였습니다.

01 / 실행 화면

TXT를 엑셀로 바꾼 모습

TXT의 내용을 순번·식별번호·이름·요청일자·부서·담당자·연락처의 7개 열로 나눕니다.

02 / 주요 기능

번호와 열 순서를 지키며 합칩니다.

합칠 파일 고르기

선택창에서 고르거나 드래그해 TXT 파일을 추가합니다. 목록에서 파일을 빼거나 순서를 바꿀 수 있습니다.

TXT 항목 나누기

EUC-KR 문자를 읽고 |에서 항목을 나눠, 정해진 7개 열에 넣습니다.

번호 앞의 0 보존

값을 문자열로 저장해 순번이나 식별번호 앞의 0이 사라지지 않게 합니다.

엑셀 형식 선택

XLSX는 Excelize로 저장합니다. XLS는 설치된 Microsoft Excel을 COM으로 불러와 변환합니다.

03 / 사용 순서

파일 선택부터 저장 결과 확인까지

  1. TXT 파일 선택합칠 순서와 저장 폴더, XLSX·XLS 형식을 정합니다.
  2. 엑셀로 변환파일의 문자 인코딩을 바꾸고 항목을 나눠 엑셀 행에 차례로 넣습니다.
  3. 저장 결과 확인변환한 행 수와 파일을 저장한 위치가 표시됩니다.
04 / 사용한 기술

Go와 Wails로 만든 Windows 앱

개발 언어
Go · JavaScript · HTML · CSS
앱 프레임워크
Wails

Excelize · Go x/text
빌드 도구

입력 형식
EUC-KR로 저장한 TXT 파일. 항목은 |로 구분합니다.
출력 형식
7개 열에 문자열을 담아 XLSX 또는 XLS로 저장합니다.
실행·연동
Windows에서 실행하며 XLS 변환에는 Microsoft Excel COM을 사용합니다.

XLS로 저장하려면 PC에 Microsoft Excel이 설치되어 있어야 합니다.

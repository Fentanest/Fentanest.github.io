03 / 주요 기능

저장과 공유는 이렇게 처리합니다.

휴대폰에 저장

신고 목록과 상세 내용을 휴대폰의 SQLite에 저장합니다. 저장한 자료로 검색·지도·통계를 보여주고, 백업과 복원도 지원합니다.

자료 공유

사용자 계정과 공유 동의를 확인한 뒤 자료를 전송합니다. 전송에 실패한 자료는 다시 보내고, 공유 동의 철회와 삭제 요청도 처리합니다.

처리 결과 정리

서버에서 신고 답변을 읽어 처리 상태, 처분 내용, 금액을 정리합니다. 파서를 수정하면 이전 답변도 다시 처리합니다.

지도와 검색

지도에서는 지역·기간·기관별 처리 결과를 봅니다. 크롬 확장에서는 본인이 공유한 완료 신고를 차량이나 주소로 찾습니다.

05 / 배포·운영

PC에서 하던 작업을 앱으로 옮겼습니다.

PC에서 모으던 신고 내역을 앱에서 직접 가져와 저장하도록 만들었습니다. 기존 사용자가 PC에 저장해 둔 자료도 앱으로 옮길 수 있게 했습니다.

사용자 요청을 받아 신고 정렬 방식과 동기화 상태 표시를 고쳤습니다. 화면을 갱신한 뒤에도 주소 검색창이 유지되도록 수정했습니다.

02 / 구현

따로 만든 화면을 연결했습니다.

앱

내 신고를 관리합니다.

신고 내역 수집, 조건별 검색, 처리 결과 통계, 지도, 변경 알림. 엑셀 내보내기와 백업·복원도 지원합니다.

지도

공유 데이터를 비교합니다.

지역·기간·기관별 필터, 지도 집계, 처리 결과 비율, 표와 차트. 내 데이터와 전체 데이터를 함께 확인합니다.

확장

기존 화면에서 조회합니다.

안전신문고 웹사이트에 조회 패널을 붙였습니다. 본인이 공유한 답변 완료 신고에서 차량·주소 이력과 담당자 통계를 확인합니다.

앱 README에 있는 통계·지도 화면을 사용했습니다. 현재 버전과 일부 차이가 있습니다.

현재 앱은 로그인 없이 ‘Demo 보기’를 제공합니다. 최신 데모 화면과 연결 시연은 추후 추가합니다.

04 / 운영

출시 후에도 고칩니다.

사용자 요청을 확인하고 반영했습니다.

정렬 방식, 동기화 상태, 화면 갱신 문제를 수정했습니다. 앱은 Google Play로 배포하고 공개 이슈에서 사용자 제보를 받습니다.

PC 수집 도구를 모바일로 옮겼습니다.

기존 PC 연동 방식은 종료했습니다. 현재는 모바일 앱이 직접 동작하며, 기존 데이터를 옮기는 절차도 마련했습니다.

기능별로 기술을 나눴습니다.

앱은 Flutter·Dart와 SQLite, 지도는 React·TypeScript, 확장은 JavaScript·Manifest V3를 사용했습니다. 데이터 정리와 공유 기능은 별도 서비스로 연결했습니다.

브라우저에서 파일을 고르고 결과를 저장합니다.

Word Compare와 ExcelMerger를 웹에서 쓸 수 있게 다시 만들었습니다. 파일 형식에 맞는 라이브러리를 쓰고, 파일 읽기와 계산은 Web Worker에서 실행합니다.

문서·엑셀 파일은 사용자의 브라우저 안에서 읽고 계산합니다. 결과는 파일로 내려받고, 화면과 실행 코드는 정적 웹페이지로 배포합니다.

03 / 설치형 도구

계약서 비교와 엑셀 파일 병합

WORD COMPARE

계약서·규정 비교

Microsoft Word의 비교 기능으로 변경 추적 문서를 만들고, 추가·삭제 내역을 엑셀 보고서로 정리합니다. 계약서 검토에 사용했습니다.

개발 언어
Python · Rust(문서 구조 추출 보조)
라이브러리
PySide6 · python-docx · XlsxWriter
Office 연동
Microsoft Word COM
입력·출력
Word 문서 두 개를 비교해 변경 추적 DOCX와 XLSX 보고서를 만듭니다.
빌드·배포
PyInstaller · Windows 실행파일
저장소·실행파일↗

04 / PETI

공직윤리 자료를 엑셀로 바꿉니다.

공직윤리시스템의 TXT 파일 여러 개를 전산 입력용 엑셀로 합칩니다. 값은 정해진 7개 열에 문자열로 저장해 번호 앞의 0도 유지합니다.

파일을 합칠 순서와 저장 위치를 고르고 XLSX 또는 XLS로 저장합니다.

Go · JavaScriptWails · Excelize

XLS 변환에는 Microsoft Excel이 필요합니다.

05 / 보고서 작성 자동화

DB에서 내려받은 엑셀로 금감원 보고서를 만듭니다.

DB에서 내려받은 엑셀의 필요한 열을 Google Sheets에 올립니다. 사용자가 시트에서 재계산을 누르면 Apps Script가 업무보고서와 상시감시보고서를 계산합니다.

개발 언어
Python · JavaScript
라이브러리
Flask · pandas · openpyxl
외부 API
Google Sheets API · Apps Script API
실행 환경
로컬 웹 앱 · Google Apps Script

올린 자료와 중간 계산, 보고서를 각각 다른 탭에 두고 행 수와 잔액 합계를 검증표에 남깁니다.

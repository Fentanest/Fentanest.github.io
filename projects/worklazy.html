개발 배경

Word Compare와 ExcelMerger는 업무에서 쓰기 위해 만든 설치형 프로그램이었습니다. 배포 파일의 용량이 크고 사용자가 내려받아 실행 환경을 준비해야 해서, 다른 사람에게 간편하게 전달할 수 있는 웹 도구로 다시 만들었습니다.

구현과 배포

파일 형식에 맞는 라이브러리를 쓰고, 파일 읽기와 계산은 Web Worker에서 실행합니다. 문서·엑셀 파일을 사용자의 브라우저 안에서 처리하고 결과를 내려받도록 구성했습니다.

화면과 실행 코드를 정적 웹페이지로 배포해 링크만 전달하면 이용할 수 있게 했습니다. 설치 과정을 줄이고 도구들을 한곳에 모아, 사용자가 필요한 작업을 바로 선택할 수 있도록 개선했습니다.

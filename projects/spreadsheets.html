05 / SPREADSHEET APPLICATION

엑셀로 만든
실무자용 대시보드

전산 환경이 부족한 조직에서 사용할 조회·집계 도구를 만들었습니다.
차입자·투자자·상품·채권 원장을 연결해 실무자가 필요한 정보를 확인하도록 구성했습니다.

Excel원장 연결 · 함수조회·집계 화면 5종
제작 목적

실무에 필요한 조회 기능을 엑셀로 구성했습니다.

별도 업무 프로그램을 충분히 갖추기 어려운 환경에서 만들었습니다. 원자료를 연결하고 회원·상품 단위 조회, 잔액·연체율 집계, 기관별 투자 현황을 한 파일에서 확인하도록 구성했습니다.

아래 이미지는 엑셀로 만든 대시보드를 Google Sheets에서 연 화면입니다. 개인·회사 식별정보를 가렸습니다.

도구
Excel · Google Sheets 열람 화면
구성
원장 간 키 연결 · 수식 기반 조회·집계
확인되는 함수
LET · VLOOKUP · IF · IFNA · HYPERLINK
화면
회원·상품 검색 · 잔액·연체율 · 투자 현황
SCREEN 01

회원별 대출 현황

회원 정보를 조회하고 상품별 취급액·잔액·상환 상태를 확인합니다.

SCREEN 02

상품별 잔액·연체율 집계

상품 유형별 취급액, 잔액, 평균금리와 연체율을 집계합니다.

SCREEN 03

부동산 담보대출 현황

월별 실적을 상환·매각·연체 상태로 나누어 확인합니다.

SCREEN 04

투자상품 목록

계약·만기일, 잔액, 기관별 투자액과 비율을 조회합니다.

SCREEN 05

상품 통합 검색

상품 조건과 상환 상태로 검색하고 잔액·금리·기간을 확인합니다.

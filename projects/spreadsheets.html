PROJECT 03 / 실무 대시보드

엑셀로 만든
업무 조회 화면

차입자·투자자·채권 데이터를 연결했습니다.
별도 업무 프로그램 없이 필요한 정보와 집계값을 확인하도록 만들었습니다.

실무 제작엑셀·스프레드시트실제 화면 5종

제작 배경

전산에서 안 보이던
정보를 꺼냈습니다.

기존 전산 화면만으로는 필요한 정보를 한 번에 확인하기 어려웠습니다. 원자료를 연결해 조회·검증용 대시보드를 만들었습니다.

엑셀로 만든 대시보드를 Google Sheets에서 연 화면입니다. 개인정보를 가린 실제 업무 화면 5장을 담았습니다.

SCREEN 01

회원별 대출 현황

회원 정보를 조회하고 상품별 취급액·잔액·상환 상태를 한 화면에 표시합니다.

SCREEN 02

상품별 잔액·연체율 집계

상품 유형별 취급액, 잔액, 평균금리와 연체율을 집계합니다.

SCREEN 03

부동산 담보대출 현황

월별 취급 실적을 상환·매각·연체 상태로 나누어 확인합니다.

SCREEN 04

투자상품 목록

상품별 계약·만기일, 잔액, 기관별 투자액과 투자 비율을 조회합니다.

SCREEN 05

상품 통합 검색

상품 정보와 상환 상태를 검색하고 잔액·금리·기간을 확인합니다.

필요한 자료를 연결하고 조회·집계한 실무 사례입니다.

계약서 수정 전후 비교

필요했던 일
계약서 수정본을 받으면 어디가 바뀌었는지 확인하고 상사에게 보고해야 했습니다.
만든 방식
Word의 비교 기능으로 변경 내용이 표시된 문서를 만들고, 수정 전후 문장을 엑셀에 나란히 정리했습니다.
사용한 업무
계약서 검토와 변경 내용 보고에 썼습니다. 이후 브라우저에서도 문서를 비교할 수 있게 만들었습니다.

회원·대출 관리 시트

필요했던 일
당시 전산에서는 회원·상품·대출 정보를 한눈에 보기 어려웠습니다.
만든 방식
따로 관리하던 자료를 시트에 연결했습니다. 열 이름으로 필요한 값을 찾게 해 자료의 열 순서가 바뀌어도 사용할 수 있게 했습니다.
사용한 업무
회원별 대출, 상품별 잔액·연체율, 기관별 투자 내역을 확인하는 데 썼습니다.

금감원 보고자료 계산

필요했던 일
보고서를 작성할 때마다 같은 항목을 다시 집계해야 했습니다.
만든 방식
대출 자료에서 보고에 필요한 항목을 정리하고, 엑셀 수식으로 합계를 계산하도록 만들었습니다.
사용한 업무
사내망에서 금융감독원에 제출할 보고자료를 작성할 때 썼습니다.
03 / 작업 방식

사용할 자료와 결과부터 확인합니다.

  1. 확인어떤 자료를 받아 어떤 결과를 만들어야 하는지, 어디에서 쓸 것인지 확인합니다.
  2. 제작자료를 처리할 순서와 항목을 정리한 뒤 프로그램을 만듭니다.
  3. 검증입력한 자료와 결과를 대조해 빠진 값이나 계산 차이를 확인합니다.

개인 프로젝트는 필요한 기능을 정하고 AI 개발 도구로 코드를 작성합니다. 결과를 직접 확인하고 배포한 뒤, 사용 중 생기는 문제를 수정합니다.
